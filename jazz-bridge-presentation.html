01 — 문제 정의

왜 재즈 팬들은
공연을 놓칠까?

재즈 공연은 주로 소규모 클럽에서 열리고, 공연 정보는 각 클럽의 SNS에 산발적으로 올라옵니다. 체계적인 정보 수집 수단이 없어 팬들이 직접 일일이 확인해야 하는 구조입니다.

📱
정보 분산
인스타그램, 네이버 블로그, 카카오 채널 등 각기 다른 플랫폼에 공연 정보가 흩어져 있음
🔍
검색 불가
날짜, 지역, 뮤지션으로 공연을 통합 검색할 수 있는 서비스가 존재하지 않음
🎟
예매 불편
DM, 전화, 현장 결제 등 공연장마다 예약 방식이 달라 일관된 경험이 없음
02 — 솔루션

Jazz Bridge가
해결하는 방법

SNS 자동 수집 + AI 파싱 파이프라인으로 공연 정보를 자동화하고, 통합 예매까지 연결합니다.

🤖
SNS 자동 수집
+ AI 파싱
블로그·홈페이지 크롤링 후 Claude Haiku로 날짜·장소·뮤지션 자동 추출. 건당 ₩1~3원.
🗓
날짜 / 지역
/ 뮤지션 필터
오늘 밤부터 이번 달까지, 홍대·이태원·강남 지역별, 팔로우 뮤지션별 즉시 탐색.
🔔
뮤지션 팔로우
& 알림
팔로우한 뮤지션의 새 공연 등록 시 푸시 알림. 핵심 리텐션 기능.
💳
통합 예매
파트너 공연장 인앱 결제. 토스페이먼츠 연동, 수수료 3~5% 수익 모델.
기술 스택
크롤러 (requests + BS4)권장
JS 렌더링 (Playwright)보조
AI 파싱 (Claude Haiku)권장
DB (PostgreSQL)핵심
스케줄러 (APScheduler)핵심
인스타그램 직접 크롤링약관 주의
결제 (토스페이먼츠)4단계
DB 핵심 테이블
event (공연)핵심
venue (공연장)핵심
artist (뮤지션)핵심
event_artist (출연진)중간
user (사용자)중간
user_artist_follow중간
booking (예매)4단계
수익 모델
예매 수수료3~5%
공연장 구독 (B2B)월정액

03 — MVP 로드맵

20주 안에
출시까지

크롤러 구축부터 예매 수익화까지, 4단계로 나눈 현실적인 MVP 로드맵입니다.

1단계 · 1~4주
크롤러 + DB
✓ 크롤러 파이프라인 구축
✓ Claude Haiku 파싱 연동
✓ PostgreSQL DB 구축
✓ APScheduler 자동화
2단계 · 5~8주
MVP 앱
✓ 홈 / 검색 / 캘린더
✓ 뮤지션 팔로우 & 알림
✓ 공연장 / 아티스트 프로필
✓ 앱스토어 배포
3단계 · 9~14주
베타 + B2B
✓ 베타 테스트 (50개 클럽)
✓ 공연장 파트너십 체결
✓ 공연 등록 직접 입력
✓ 피드백 반영 개선
4단계 · 15~20주
정식 출시
✓ 토스페이먼츠 예매 연동
✓ 수수료 수익화 시작
✓ B2B 구독 모델 런칭
✓ 전국 확장
